# 📚 Subject & Indefinite Pronouns in Spanish

---

## 👤 Subject Pronouns

---

### Yo — *I*

```
Yo estudio español.
jjo es-tu-dio es-pa-nyol
I study Spanish.
```

---

### Usted — *You (formal)*

```
Usted trabaja en la oficina.
us-ted tra-ba-ha en la o-fi-si-na
You work in the office.
```

---

### Él — *He*

```
Él lee un libro.
el le-e un li-bro
He reads a book.
```

---

### Ella — *She*

```
Ella canta bien.
e-ya kan-ta bien
She sings well.
```

---

### Nosotros / Nosotras — *We*

```
Nosotros comemos juntos.
no-so-tros ko-me-mos hun-tos
We eat together.
```

---

### Ellos / Ellas — *They*

```
Ellos juegan fútbol.
e-jjos hwe-gan fut-bol
They play soccer.
```

---

### Ustedes — *You all*

```
Ustedes viajan mañana.
us-te-des via-han ma-nya-na
You all travel tomorrow.
```

---

## 🔵 Indefinite Pronouns

---

### Alguien — *Someone*

```
Alguien llamó a usted.
al-gien jja-mo a us-ted
Someone called you.
```

---

### Algo — *Something*

```
Ustedes quieren algo de comer.
us-te-des kie-ren al-go de ko-mer
You all want something to eat.
```

---

### Nadie — *No one*

```
Nadie respondió a ustedes.
na-die res-pon-dio a us-te-des
No one answered you all.
```

---

### Nada — *Nothing*

```
No vi nada.
no bi na-da
I saw nothing.
```

---

### Todo / Toda — *Everything*

```
Todo está listo para ustedes.
to-do es-ta lis-to pa-ra us-te-des
Everything is ready for you all.
```
