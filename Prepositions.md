#### Prepositions:
1. **At** - **En / A**

```
Estoy en la escuela. 
Estoi en la escuela. 
I am at school.
```

```
Llegué a las tres. 
jjege a las tres. 
I arrived at three.
```

2. **After** - **Después de**

```
Vamos a cenar después de trabajar. 
bamos a cenar después de trabahar. 
We are going to have dinner after work.
```

3. **For** - **Para / Por**

```
Este regalo es para ti. 
Este regalo es para ti. 
This gift is for you.
```

```
Gracias por tu ayuda. 
Gracias por tu ajjuda. 
Thank you for your help.
```

4. **From** - **De / Desde**

```
Soy de España. 
Soy de España. 
I am from Spain.
```

```
Trabajo desde casa. 
Trabaho desde casa. 
I work from home.
```

5. **In** - **En**

```
Vivo en Madrid. 
bivo en Madrid. 
I live in Madrid.
```

6. **On** - **En / Sobre**

```
El libro está en la mesa. 
El libro está en la mesa. 
The book is on the table.
```

```
La lámpara está sobre el escritorio. 
La lámpara está sobre el escritorio. 
The lamp is on the desk.
```

7. **To** –  **A**

```
Voy a la tienda 
boi a la tienda 
I am going to the store)
```

8 .**With** –  **Con**

```
Salgo con mis amigos 
Salgo con mis amigos 
I go out with my friends)
```
