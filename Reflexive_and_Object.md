# 📚 Lesson: Reflexive and Object Pronouns

## 📌 What Are These?

> Pronouns replace nouns so you don't have to repeat the same word.
> You need these to have **real conversations** in Costa Rica! 💪


### 🔔 The big difference:

In **English** → reflexive pronouns come **at the end**
> *"I wash **myself**"*

In **Spanish** → reflexive pronouns come **before the verb**
> *"**Me** lavo"*


---

## 🔵 Part 1: Object Pronouns (Direct / Indirect)

> These tell us **who** receives the action.

---

### **Me** — me

```
Ella me ve
e-jja me be
She sees me
```

```
Me dio un regalo
me dio un re-ga-lo
She gave me a gift
```

---

### **Le** — you (formal, indirect)

```
Le escribí una carta
le es-kri-bi u-na kar-ta
I wrote you a letter
```

---

### **Lo** — him / it / you (formal, direct - male)

```
Lo invité a la fiesta
lo in-bi-te a la fies-ta
I invited him to the party
```

```
Lo respeto, usted
lo res-pe-to us-ted
I respect you
```

---

### **La** — her / it / you (formal, direct - female)

```
La vi ayer
la bi a-jjer
I saw her yesterday
```

---

### **Nos** — us

```
Nos ayudaron
nos a-jju-da-ron
They helped us
```

---

### **Los** — them / you all (male or mixed group)

```
Los vi en el parque
los bi en el par-ke
I saw them in the park
```

```
Los invito, ustedes
los in-bi-to us-te-des
I invite you all
```

---

### **Las** — them / you all (female group)

```
Las llamé
las jja-me
I called them
```

---

## 🟢 Part 2: Reflexive Pronouns

> Reflexive pronouns are used when **you do the action to yourself**.
> Very common in daily life! 🌟

---

### **Me** — myself

```
Me lavo las manos
me la-bo las ma-nos
I wash my hands
```

---

### **Se** — yourself (formal)

```
¿Se siente bien, usted?
se sien-te bien us-ted
Do you feel good?
```

---

### **Se** — himself / herself / itself

```
Él se levanta temprano
el se le-ban-ta tem-pra-no
He gets up early
```

```
Ella se peina
e-jja se pei-na
She brushes her hair
```

---

### **Nos** — ourselves

```
Nos preparamos para la reunión
nos pre-pa-ra-mos pa-ra la re-u-nion
We prepare ourselves for the meeting
```

---

### **Se** — themselves / yourselves

```
Ellos se divierten
e-jjos se di-bier-ten
They enjoy themselves
```

```
¿Se acuerdan, ustedes?
se a-kuer-dan us-te-des
Do you all remember?
```

---

## 📋 Quick Reference Table

| Pronoun | Type               | Meaning                                   |
| ------- | ------------------ | ----------------------------------------- |
| **Me**  | Object / Reflexive | me / myself                               |
| **Le**  | Indirect Object    | you (formal) / him / her                  |
| **Lo**  | Direct Object      | him / it / you (formal, male)             |
| **La**  | Direct Object      | her / it / you (formal, female)           |
| **Nos** | Object / Reflexive | us / ourselves                            |
| **Los** | Direct Object      | them / you all (male)                     |
| **Las** | Direct Object      | them / you all (female)                   |
| **Se**  | Reflexive          | himself / herself / themselves / yourself |
