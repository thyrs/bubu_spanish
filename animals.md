## 🗣️ Basic Sentences - Learn These!

### ➡️ "I see a..." = **Yo veo un/una...**

```
Yo veo un perro
yo be-o un pe-rro
I see a dog
```

```
Yo veo un gato
yo be-o un ga-to
I see a cat
```

```
Yo veo una vaca
yo be-o u-na ba-ka
I see a cow
```

```
Yo veo un pájaro
yo be-o un pa-ha-ro
I see a bird
```

> 🔔 **Grammar tip:**
> - **un** = a (for male words) → un perro, un gato
> - **una** = a (for female words) → una vaca, una serpiente

---

### ➡️ "There is a..." = **Hay un/una...**

```
Hay un mono en el árbol
ay un mo-no en el ar-bol
There is a monkey in the tree
```

```
Hay una serpiente aquí
ay u-na ser-pien-te a-ki
There is a snake here
```

```
Hay un caballo grande
ay un ka-ba-yo gran-de
There is a big horse
```

---

### ➡️ "I like / I don't like" = **Me gusta / No me gusta**

```
Me gusta el pollo
me gus-ta el po-yo
I like chicken
```

```
No me gusta la serpiente
no me gus-ta la ser-pien-te
I don't like the snake
```

```
Me gusta el mono
me gus-ta el mo-no
I like the monkey
```

> 🔔 **Grammar tip:**
> - **el** = the (male) → el perro, el gato, el mono
> - **la** = the (female) → la vaca, la serpiente, la cabra

---

### ➡️ "The [animal] is..." = **El/La [animal] es...**

```
El perro es grande
el pe-rro es gran-de
The dog is big
```

```
El gato es pequeño
el ga-to es pe-ke-nyo
The cat is small
```

```
El elefante es muy grande
el e-le-fan-te es muy gran-de
The elephant is very big
```

```
La cabra es blanca
la ka-bra es blan-ka
The goat is white
```
