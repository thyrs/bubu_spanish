## 🗣️ Basic Sentences - Learn These!

### ➡️ "I am a..." = **Yo soy...**

```
Yo soy enfermera
jjo soi en-fer-me-ra
I am a nurse
```

```
Yo soy cocinero
jjo soi ko-si-ne-ro
I am a cook
```

```
Yo soy maestra
jjo soi ma-es-tra
I am a teacher
```

```
Yo soy cajera
jjo soi ka-he-ra
I am a cashier
```

> 🔔 **Grammar tip:**
> In Spanish you do NOT say **"un/una"** with your job after **soy**
> ✅ **Yo soy enfermera** → I am a nurse
> ❌ ~~Yo soy una enfermera~~ ← sounds unnatural

---

### ➡️ "I want to work as..." = **Quiero trabajar como...**

```
Quiero trabajar como enfermera
kie-ro tra-ba-har ko-mo en-fer-me-ra
I want to work as a nurse
```

```
Quiero trabajar como cocinera
kie-ro tra-ba-har ko-mo ko-si-ne-ra
I want to work as a cook
```

```
Quiero trabajar como cajera
kie-ro tra-ba-har ko-mo ka-he-ra
I want to work as a cashier
```

---

### ➡️ "Do you have work?" = **¿Hay trabajo?**

```
¿Hay trabajo aquí?
ay tra-ba-ho a-ki
Is there work here?
```

```
Necesito trabajo
ne-se-si-to tra-ba-ho
I need work
```

```
Busco trabajo
bus-ko tra-ba-ho
I am looking for work
```

```
¿Dónde puedo trabajar?
don-de pue-do tra-ba-har
Where can I work?
```

> 🔔 **These 4 sentences are GOLD! You will use them in real life in Costa Rica! Learn them by heart!**

---
