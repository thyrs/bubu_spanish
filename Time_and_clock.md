# ⏰ Lesson: Time (El Tiempo)

---

## 🕐 Telling the Time / Diciendo la Hora

### ➡️ "What time is it?" = **¿Qué hora es?**

```
¿Qué hora es?
ke o-ra es
What time is it?
```

```
Es la una
es la u-na
It's one o'clock
```

```
Son las dos
son las dos
It's two o'clock
```

> 🔔 **Grammar tip:**
> - **Es la una** → only for 1 o'clock
> - **Son las dos/tres/cuatro...** → for all other hours

---

### ➡️ Telling exact time / Hora exacta

```
Son las doce y treinta y siete
son las do-se i trein-ta i sie-te
It's twelve thirty-seven (12:37 PM)
```

```
Son las ocho y cinco
son las o-cho i sin-ko
It's eight oh five (8:05 PM)
```

> 🔔 **Remember:** **y** = "and" → Son las ocho **y** cinco = eight **and** five

## 🗣️ Basic Sentences - Learn These!

### ➡️ Day / Día

```
Hoy es un buen día
oy es un buen di-a
Today is a good day
```

---

### ➡️ Evening / Tarde

```
Nos vemos por la tarde
nos be-mos por la tar-de
See you in the evening
```

---

### ➡️ Hour / Hora

```
¿A qué hora llegas?
a ke o-ra jje-gas
At what hour do you arrive?
```

---

### ➡️ Minute / Minuto

```
Espera un minuto, por favor
es-pe-ra un mi-nu-to por fa-bor
Wait a minute, please
```

---

### ➡️ Month / Mes

```
El próximo mes es diciembre
el pro-xi-mo mes es di-siem-bre
Next month is December
```

---

### ➡️ Morning / Mañana ⚠️

> 🔔 **Important! Mañana has TWO meanings:**
> - **esta mañana** = this morning
> - **mañana** = tomorrow

```
Buenos días, ¿cómo estás esta mañana?
bue-nos di-as ko-mo es-tas es-ta ma-nya-na
Good morning, how are you this morning?
```

```
Mañana tengo una reunión importante
ma-nya-na ten-go u-na re-u-nion im-por-tan-te
Tomorrow I have an important meeting
```

---

### ➡️ Night / Noche

```
Buenas noches, que descanses
bue-nas no-ches ke des-kan-ses
Good night, rest well
```

---

### ➡️ Time / Tiempo

```
No tengo mucho tiempo libre hoy
no ten-go mu-cho tiem-po li-bre oy
I don't have much free time today
```

---

### ➡️ Today / Hoy

```
Hoy es lunes
oy es lu-nes
Today is Monday
```

---

### ➡️ Tonight / Esta noche

```
Esta noche vamos al cine
es-ta no-che ba-mos al si-ne
Tonight we are going to the movies
```

---

### ➡️ Week / Semana

```
La semana tiene siete días
la se-ma-na tie-ne sie-te di-as
The week has seven days
```

---

### ➡️ Yesterday / Ayer

```
Ayer fue domingo
a-jjer fue do-min-go
Yesterday was Sunday
```
