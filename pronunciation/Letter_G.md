# 🔤 Spanish Pronunciation: The Letter **G**

---

## Why This Matters for You

The letter **G in Spanish has TWO different sounds.**
Which sound depends on the **letter that comes after G.**
You must learn this — you will see G in MANY words every day!

---

## The Two Sounds of G

### Sound 1 — Hard G (like English "go")
**G + A, O, U = hard G sound**

```
ga = ga  (like "garden")
go = go  (like "go")
gu = gu  (like "good")
```

### Sound 2 — Soft G (like Spanish J = strong H sound)
**G + E, I = soft G = same as J sound!**

```
ge = he  (strong breath sound)
gi = hi  (strong breath sound)
```

---

## The Simple Rule

```
G before A = hard G → 

gato
ga-to
cat
```

```
G before O = hard G → 

gobierno
go-bier-no
government
```

```
G before U = hard G → 

agua
a-gua
water
```

```
G before E = H sound → 

gente
hen-te
people
```

```
G before I = H sound → 

agente
a-hen-te
agent
```

## ⚠️ The Silent U — GUE and GUI

When Spanish wants a **hard G before E or I**, it adds a silent U:

> **GUE = hard G + E** (the U is silent!)
> **GUI = hard G + I** (the U is silent!)

```
guitarra
gi-ta-rra
guitar (U is silent!)
```

```
guerra
ge-rra
war (U is silent!)
```

```
guía
gi-a
guide (U is silent!)
```

```
siguiente
si-gien-te
following (U is silent!)
```

> 🚨 **GUE ≠ "gwe"** — the U is completely silent here!
> 🚨 **GUI ≠ "gwi"** — the U is completely silent here!

---

## ✅ The Complete G Rule — Easy to Remember!

```
GA, GO, GU = hard G sound → like "go"
GE, GI     = H sound      → like J
GUE, GUI   = hard G       → U is silent
```

> 🧠 **Easy way to remember:**
> **G before A, O, U = Go sound**
> **G before E, I = H sound (same as J!)**
