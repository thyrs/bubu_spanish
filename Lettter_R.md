# 🗣️ Spanish R and RR Pronunciation Lesson

---

## The Two R Sounds in Spanish

Spanish has **two different R sounds**. This is very important!
Getting them wrong can change the meaning of the word! 😮

---

## Sound 1 — The Soft R (single R)

> Tongue **taps once** behind your top teeth. Very quick and light.
> Like the **"d"** sound in American English *"butter"* or *"ladder"*

### When to use Soft R:
- ✅ R in the **middle** of a word
- ✅ R at the **end** of a word

### Examples:

```
pero
pe-ro
but / however
```

```
caro
ka-ro
expensive
```

```
comer
ko-mer
to eat
```

```
amor
a-mor
love
```

```
hablar
a-blar
to speak / to talk
```

---

## Sound 2 — The Strong RR (rolled R)

> Tongue **vibrates many times** behind your top teeth.
> Like a motor or a cat purring 😸 **"rrrrr"**

### When to use Strong RR:
- ✅ **RR** written between two vowels
- ✅ **Single R** at the **START** of a word
- ✅ **Single R** after **L, N, S**

### Examples:

```
perro
pe-RRo
dog
```

```
carro
ka-RRo
car
```

```
rico
RRi-ko
delicious / rich
```

```
ropa
RRo-pa
clothes
```

```
alrededor
al-RRe-de-dor
around
```

---

## ⚠️ DANGER PAIRS — Same Letters, Different Meaning!

These words look similar but mean **completely different things!**

```
| Soft R | Meaning   | Strong RR | Meaning   |
| ------ | --------- | --------- | --------- |
| pero   | but       | perro     | dog       |
| caro   | expensive | carro     | car       |
| para   | for       | parra     | grapevine |
```
### Listen to the difference:

```
pero / perro
pe-ro / pe-RRo
but / dog
```

> ❌ Saying **"pero"** (soft) when you mean **"perro"** (strong)
> sounds like you said **"but"** instead of **"dog"**! 😂

---

## 🧠 Simple Rules to Remember

```
R at START of word = STRONG roll
RRo-pa = ropa
```

```
RR in MIDDLE of word = STRONG roll
pe-RRo = perro
```

```
R in MIDDLE of word = soft tap
pe-ro = pero
```

```
R at END of word = soft tap
ko-mer = comer
```

## 💡 Beginner Tip

> If rolling the R is hard right now — **don't worry!**
> People will still understand you. 😊
> Practice every day by saying:

```
rápido rico rico rápido
RRa-pi-do RRi-ko RRi-ko RRa-pi-do
fast delicious delicious fast
```

> Say it **faster and faster** each day! 🚀
