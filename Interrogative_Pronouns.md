# ❓ Lesson: Interrogative Pronouns (Question Words)

---

## 📌 What Are These?

> These are the words you use to **ask questions** in Spanish.
> You will need these **every single day** in Costa Rica! 💪

---

## 🔵 The Question Words

---

### **¿Quién?** — Who?

```
¿Quién es usted?
kien es us-ted
Who are you?
```

---

### **¿Qué?** — What?

```
¿Qué hacen ustedes?
ke a-sen us-te-des
What are you all doing?
```

---

### **¿Cuál?** — Which?

```
¿Cuál prefiere usted?
kwal pre-fie-re us-ted
Which do you prefer?
```

---

### **¿Cuánto / Cuánta?** — How much?

> 🔔 **Cuánto** = male words → *¿Cuánto dinero?*
> 🔔 **Cuánta** = female words → *¿Cuánta agua?*

```
¿Cuánto cuesta?
kwan-to kues-ta
How much does it cost?
```

---

### **¿Cuántos / Cuántas?** — How many?

> 🔔 **Cuántos** = male/mixed group → *¿Cuántos perros?*
> 🔔 **Cuántas** = female group → *¿Cuántas personas?*

```
¿Cuántas quieren ustedes?
kwan-tas kie-ren us-te-des
How many do you all want?
```

---

## 📋 Quick Reference Table

| Question Word    | Meaning   | Example               |
| ---------------- | --------- | --------------------- |
| **¿Quién?**      | Who?      | ¿Quién es usted?      |
| **¿Qué?**        | What?     | ¿Qué hacen ustedes?   |
| **¿Cuál?**       | Which?    | ¿Cuál prefiere usted? |
| **¿Cuánto/a?**   | How much? | ¿Cuánto cuesta?       |
| **¿Cuántos/as?** | How many? | ¿Cuántas quieren?     |
