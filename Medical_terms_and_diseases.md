## PART 2 — Key Sentences (The ones you WILL need!)

### 🔴 Saying what is wrong with YOU:

```
Estoy enferma.
es-toy en-fer-ma
I am sick.
```

```
Tengo fiebre.
ten-go fie-bre
I have a fever.
```

```
Tengo tos.
ten-go tos
I have a cough.
```

```
Tengo dolor de cabeza.
ten-go do-lor de ka-be-sa
I have a headache.
```

```
Tengo dolor aquí.
ten-go do-lor a-ki
I have pain here. (point to where it hurts!)
```

```
Necesito medicina.
ne-se-si-to me-di-si-na
I need medicine.
```

```
Necesito ir al hospital.
ne-se-si-to ir al os-pi-tal
I need to go to the hospital.
```

---

### 🔵 Asking about someone else:

```
¿Estás enfermo?
es-tas en-fer-mo?
Are you sick?
```

```
¿Tienes fiebre?
tie-nes fie-bre?
Do you have a fever?
```

```
¿Tienes dolor?
tie-nes do-lor?
Do you have pain?
```

```
¿Necesitas medicina?
ne-se-si-tas me-di-si-na?
Do you need medicine?
```

---

### 🟢 Talking about someone else (a child, a patient):

```
Ella está enferma.
e-ya es-ta en-fer-ma
She is sick.
```

```
Él tiene fiebre.
el tie-ne fie-bre
He has a fever.
```

```
El niño tiene tos.
el ni-ño tie-ne tos
The boy has a cough.
```

## PART 3 — Super Important phrases for the doctor! 🩺

```
Buenos días, doctor.
bwe-nos di-as dok-tor
Good morning, doctor.
```

```
Me llamo Grace. Estoy enferma.
me ya-mo gres. es-toy en-fer-ma
My name is Grace. I am sick.
```

```
Tengo dolor aquí desde ayer.
ten-go do-lor a-ki des-de a-yer
I have had pain here since yesterday.
```

```
No tengo seguro médico.
no ten-go se-gu-ro me-di-ko
I don't have medical insurance.
```

```
¿Cuánto cuesta la consulta?
kwan-to kwes-ta la kon-sul-ta?
How much does the appointment cost?
```

## PART 5 — The Magic Words 🔑

> Learn these 2 words and you can describe ANY sickness:

| Word | Meaning | Use it like this |
|------|---------|-----------------|
| **Tengo** | I have | Tengo + [sickness] |
| **Necesito** | I need | Necesito + [thing] |

```
Tengo... + (fiebre / tos / dolor / malaria)
ten-go...
I have... + (fever / cough / pain / malaria)
```

```
Necesito... + (medicina / hospital / doctor)
ne-se-si-to...
I need... + (medicine / hospital / doctor)
```
